HTMLHTML es el lenguaje de marcado estándar que define la estructura y el contenido de las páginas web.


CSS(Cascading Style Sheets, u hojas de estilo en cascada) es el lenguaje de diseño que se usa para definir y crear el aspecto visual de una página web escrita en HTML o XML


JavaScript (JS)JavaScript (JS) es un lenguaje de programación interpretado que se utiliza principalmente para crear páginas web interactivas y dinámicas.
